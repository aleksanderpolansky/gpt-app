# ADR-ADM5C3B-002 — API регистрации намерения выполнения

Дата: 2026-10-17. Статус: proposed. Использование агентами: **false**.

## Назначение

Проверить безопасную связь установленной вручную миграции ADM-5C.3B и отдельного административного API в Next.js.

Маршрут `/admin/agent-attempts/registry` только для платформенного администратора owner/admin.
GET `/api/admin/management/agent-attempts` читает состояние снимка и реальные зарегистрированные записи, исключая полные тексты и персональные поля из ответа.
POST `register_intent` после серверной проверки доступа, источника, SHA-256, текущей версии и события `reviewed_internal` вызывает ровно одну RPC `arctor_admin_ai_attempt_register_adm5c3b_v1`.

RPC сохраняет попытку со статусом `awaiting_preflight`, события `registered`, уникальные `operation_id` и `(assignment_id, task_code, snapshot_id)`. Повторный запрос с прежним `operation_id` возвращает исходную запись; другая операция того же кандидата не должна создавать второй снимок.

## Ограничения

Подтверждение `reviewed_internal` не разрешает вызов API-модели, отправку контекста, платёж или изменение ADM-4. Новые строки `agent_execution_permitted=false`, `outbound_authorized=false`, `budget_reserved=false` являются обязательными.

GET и POST требуют серверной проверки роли; POST требует одновременной проверки origin и content-type, UUID, границ JSON и пересборки текущего контекста. Никогда не использовать удостоверение из браузерного JSON: `actor_app_user_id` только из серверной авторизации.

Прямая RPC из browser запрещена SQL GRANT/RLS. Финансы AI Billing неизменны. В коде нет импорта OpenAI/gateway, сторонних инструментов или запуска агентов.

## Приёмка

Локально: ESLint, TypeScript, build; не изменять существующие файлы и миграции. Функционально: первый GET показывает 0, первая регистрация создаёт 1 попытку + 1 событие, повтор регистрации не создаёт дубликат, GET анонимно и POST без origin запрещены, изменение первоисточника и несогласованный снимок блокируют запись. Негативные SQL сценарии и конкуренция отдельно в ADM-5C.3B QA. После этого лишь проектировать ADM-5C.4, не включать AI.

Этот документ записан в `docs/admin-library` в исходниках и должен быть добавлен в интерфейсный реестр библиотеки отдельной проверяемой операцией; наличие файла само по себе не публикует его на странице библиотеки.
