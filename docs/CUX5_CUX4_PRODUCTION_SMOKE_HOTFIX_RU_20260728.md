# ARCTor.app — CUX5/CUX4 Production Smoke Hotfix

**Дата:** 28.07.2026
**Baseline:** `main @ 18670ff1dfd9eda31d97ab323d36f931147cd064`

## Причина

Production smoke выявил три дефекта:

1. поле поиска существующих объектов было технически создано, но исчезало в узкой правой колонке из-за трёхколоночной раскладки;
2. exact-активность только с началом блокировалась, если пользователь не заполнил конец или длительность;
3. semantic run создавался при сохранении, но переход в `processing` происходил только внутри отложенного callback, поэтому пользователь мог видеть впечатление, что анализ начинается после открытия «Подробнее».

## Исправление CUX5

Поле поиска вынесено в отдельную строку полной ширины.
Фильтры политики ветви и уровня дерева расположены ниже в адаптивной сетке из двух колонок.

Поиск по-прежнему отправляет `q` в существующий endpoint и работает по:

- названию;
- псевдонимам;
- полному пути.

Поиск родителя при создании нового объекта остаётся отдельным полем.

## Исправление exact start-only

Закреплено правило:

```text
exact + начало + нет конца + нет длительности
→ длительность 15 минут
→ конец = начало + 15 минут
```

Правило применяется:

- в локальном timing contract;
- при ручном вводе начала;
- после semantic preview;
- непосредственно перед сохранением;
- повторно на API-границе.

Явный конец или явная длительность пользователя всегда имеют приоритет.

## Исправление фонового анализа

Новый порядок:

```text
Добавить активность
→ canonical activity создана
→ semantic run создан
→ run синхронно переведён в processing
→ after() продолжает дорогой semantic preview
→ пользователь не ждёт результат
```

`Подробнее` по-прежнему выполняет только GET и не запускает обработку.

Если пользователь открывает контейнер сразу, он видит `processing`.
Если позже — готовый результат, `needs_clarification` или `failed`.

## Что не меняется

- Activity Container обязателен;
- canonical activity создаётся первой;
- одна exact activity имеет максимум одну calendar projection;
- AI rules не перерабатываются;
- AI suggestions объектов не добавляются;
- CUX6 не входит в этот пакет;
- миграций базы данных нет.
