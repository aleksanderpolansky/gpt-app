O-BL bridge role
The future bridge helper should orchestrate a static/no-I-O flow:
1. call readControlledActivityIntakeServerSideAuthSessionRuntimeConnection with injected/static project auth session input;
2. if connection fails, return controlled bridge failure;
3. pass connection.sessionReadModel into readControlledActivityIntakeServerSideAuthSessionRuntime;
4. if runtime adapter fails, return controlled bridge failure;
5. return staticAuthSessionResult identity from serverSideAuthSession.ts through a safe bridge result.
