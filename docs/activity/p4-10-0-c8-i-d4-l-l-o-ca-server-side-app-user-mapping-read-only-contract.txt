Purpose
This block defines the read-only contract for mapping a real Auth0 authenticated session to an internal application user.

This block is contract/report-only.
It does not implement a DB read.
It does not implement a DB write.
It does not execute SQL.
It does not call AI.
It does not integrate real auth into src/app/api/activity/controlled-intake/route.ts.
It does not insert activity_events.
It does not persist semantic candidates, Value Objects, state facts, state deltas, or state snapshots.

Fail-closed order for future implementation
1. Check diagnostic header.
2. If missing or wrong, return 403 before Auth0 session read and before DB read.
3. Read server-side Auth0 session only after diagnostic header passes.
4. Sanitize session to provider/authSubject/email/sessionId only.

8. Return sanitized mapping result.
9. Never expose raw session, raw profile, tokens, cookies, full provider payload, or internal unsafe DB rows.
10. Never write DB, never insert activity_events, never call AI.
