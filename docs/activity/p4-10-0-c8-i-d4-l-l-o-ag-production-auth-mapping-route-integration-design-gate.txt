Recommended O-AH route behavior
The route may support an additional explicit no-write verification mode for production auth mapping, for example:
- x-controlled-intake-auth-mapping-mode: production_static_preview

This mode must be clearly no-write.
It may read server-side-like preview headers only for static testing, not for production write:
- x-controlled-intake-preview-auth-subject
- x-controlled-intake-preview-mapped-app-user-id
- x-controlled-intake-preview-mapped-user-id
- x-controlled-intake-preview-mapped-actor-id
- x-controlled-intake-preview-mapped-organization-id
- x-controlled-intake-preview-mapped-space-id

Those headers must be accepted only together with:
- x-controlled-intake-no-write-preview: true
