============================================================
1. MVP dimension selection rule
============================================================

A state dimension may enter MVP only if it satisfies all conditions:
- It helps choose or filter a Next Best Action.
- It can be estimated from activity logs, user self-report, direct measurement or conservative semantic hooks.
- It is useful across multiple directions, not only one narrow feature.
- It can be represented without medical, legal, financial or social overclaim.
- It can be corrected by the user.
- It can remain private by default.
- It does not require Value Object subtypes.
- It can work as provisional signal before persistence.

3. Dimension: energy
============================================================

dimensionKey:
energy

Purpose:
Estimate whether the user currently has enough subjective or contextual energy for a proposed action.

Allowed sources:
- user_self_report: energetic or tired
- direct_measurement: sleep/rest/activity duration
- semantic_hook: sleep, meal, hydration, work shift, recovery activity
- inferred_state: provisional and explainable only

Allowed interpretation:
- Adjust NBA task intensity
- Prefer lighter or heavier action candidates

Forbidden overclaims:
- Do not infer hormones
- Do not infer medical condition
- Do not infer permanent health status
- Do not infer productivity value of the person

Possible scale later:
0-100 or low/medium/high/unknown

Default privacy:
private

Correction:
User correction overrides inference.
