Purpose
This block defines the browser/runtime verification contract for the controlled-intake route after O-CS and O-CS-REPAIR.

This block is contract/report-only.
It does not call the controlled-intake endpoint.
It does not implement a DB read.
It does not implement a DB write.
It does not execute SQL.
It does not call AI.
It does not insert activity_events.
It does not persist semantic candidates, Value Objects, state facts, state deltas, or state snapshots.
It does not enable production writes.

Required runtime test cases

Acceptable non-success interpretation for case 3
If the request body is invalid, validation failure is not a mapping failure.
If Auth0 session is missing, the route should fail before DB lookup.
If public.app_users mapping is missing, the route should fail closed with no write.
If mappingStatus is app_user_not_found, app_user_duplicate or app_user_lookup_error, this proves fail-closed behavior but not successful mapped intake preview.
