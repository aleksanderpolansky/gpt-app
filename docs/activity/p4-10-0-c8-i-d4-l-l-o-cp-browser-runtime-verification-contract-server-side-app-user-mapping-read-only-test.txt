Purpose
This block defines the browser/runtime verification contract for the diagnostic endpoint implemented in O-CO.

This block is contract/report-only.
It does not call the diagnostic endpoint.
It does not implement a DB read.
It does not implement a DB write.
It does not execute SQL.
It does not call AI.
It does not modify src/app/api/activity/controlled-intake/route.ts.

It does not persist semantic candidates, Value Objects, state facts, state deltas, or state snapshots.

Endpoint under test
/api/activity/debug/server-side-app-user-mapping-read-only-test

Required diagnostic header
- Header name: x-controlled-intake-server-side-app-user-mapping-read-only-test.
- Accepted value: enabled.

Verification environment
- Use browser console while authenticated in the app.
- Use same origin fetch.
- Do not use PowerShell for the runtime endpoint call.
- Do not use Supabase SQL Editor.
- Do not modify code during runtime verification.

Required runtime test cases
1. Missing diagnostic header.
2. Wrong diagnostic header.
3. Valid diagnostic header with current browser/Auth0 session.

Expected missing-header behavior
- HTTP status: 403.
- diagnosticHeaderAccepted: false.
- authSessionReadExecuted: false.
- authSessionFound: false.
- dbReadExecuted: false.
- dbWriteExecuted: false.
- sqlExecuted: false.
- aiCallExecuted: false.
- activityEventsInserted: false.
- controlledIntakeRouteChanged: false.
- diagnosticErrorCode: CONTROLLED_INTAKE_SERVER_SIDE_APP_USER_MAPPING_READ_ONLY_TEST_HEADER_REQUIRED.

Expected wrong-header behavior
- HTTP status: 403.
- diagnosticHeaderAccepted: false.
- authSessionReadExecuted: false.
- authSessionFound: false.
- dbReadExecuted: false.
- dbWriteExecuted: false.
- sqlExecuted: false.
- aiCallExecuted: false.
- activityEventsInserted: false.
- controlledIntakeRouteChanged: false.
- diagnosticErrorCode: CONTROLLED_INTAKE_SERVER_SIDE_APP_USER_MAPPING_READ_ONLY_TEST_HEADER_REQUIRED.

Expected valid-header authenticated behavior
- diagnosticHeaderAccepted: true.
- authSessionReadExecuted: true.
- If Auth0 session is present, authSessionFound should be true.
- trustedProvider should be auth0 when trusted Auth0 subject is present.
- trustedAuthSubjectPresent should be true when Auth0 subject exists.
- mappingStatus must be one of: mapped_user_found, app_user_not_found, app_user_duplicate, app_user_lookup_error.
- mapped_user_found is the desired success state if public.app_users contains a matching auth0_sub row.
- app_user_not_found is acceptable if user sync is missing or auth0_sub does not match public.app_users yet.
- app_user_duplicate must fail closed.
- app_user_lookup_error must fail closed.
- dbReadExecuted may be true only in the valid-header runtime test.
- dbWriteExecuted must remain false.
- sqlExecuted must remain false.
- aiCallExecuted must remain false.
- activityEventsInserted must remain false.
- controlledIntakeRouteChanged must remain false.

A later user-sync or app_users data audit may be required if mapped_user_found is expected but not returned.
