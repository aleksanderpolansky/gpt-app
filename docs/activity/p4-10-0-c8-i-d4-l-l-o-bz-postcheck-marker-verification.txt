Purpose
This postcheck closes a tooling gap in the O-BZ design gate block.

During the O-BZ inline execution, the helper function Require-Marker failed to parse because the PowerShell string used:

"STOP: Missing marker in $Label: $Marker"

As a result, Require-Marker was not defined, subsequent marker checks did not actually run, and several "OK" messages were printed without real marker verification.

This postcheck re-runs the O-BZ marker verification using the corrected safe syntax:
