The original O-V commit contains the intended authContext.ts helper, but its isolated runtime verification was invalid.

What authContext.ts does
- Defines a static auth context helper boundary.
- Builds trusted context from server-side auth identity plus server-side app user mapping.
- Builds no-write preview trusted context separately.
- Requires authenticated identity subject for production auth context.
- Requires server-side app user mapping.
- Provides assertControlledActivityIntakeTrustedContext.
- Keeps guardrails that DB/SQL/AI/semantic persistence did not happen.

What authContext.ts does not do
- Does not import Auth0.
- Does not import Supabase.

- Does not execute SQL.

- Does not write state facts, deltas, or snapshots.
- Does not change route.ts.
