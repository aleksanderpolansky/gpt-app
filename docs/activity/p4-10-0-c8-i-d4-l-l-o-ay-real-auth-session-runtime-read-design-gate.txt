Target of the future runtime read layer

Future runtime read must produce only:
- provider
- authSubject
- email if available and safe
- sessionId if available and safe
- expiresAt if available and safe
- issuedAt if available and safe
- rawSessionAvailable boolean
- readSource
- readFailed/readFailureMessage only on controlled failure

Future runtime read must not return:
- access token
- refresh token
- ID token
- raw cookie values
- raw session object
- full profile payload
- full Auth0 SDK response
- unnecessary PII
- name/picture unless separately approved later

The preferred contract should avoid direct route-level Auth0 SDK calls.
