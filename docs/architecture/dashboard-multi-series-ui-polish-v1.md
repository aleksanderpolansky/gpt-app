# ARCTor Dashboard Multi-Series UI Polish V1

Дата: 2026-09-26

## Цель

Небольшая визуальная доработка уже принятого Dashboard Unit Bands V5 без
изменения модели данных, единиц измерения или серверной аналитики.

## Изменения

1. Убирается пояснение про совместимые единицы и общую ось X.
2. Между названием Y-зоны (`Продолжительность, мин`) и графиком увеличивается
   нижний отступ: `mb-1 -> mb-3`.
3. Заголовок multi-series дополняется локализованными названиями ОН.

Пример:

`Сравнение показателей: Продолжительность ночного сна, Количество пробуждений`

Названия ОН дедуплицируются. Показываются первые три, затем компактно `+N`.

Если сохранённый title является стандартным локализованным вариантом
«Сравнение показателей», база заголовка берётся из текущей locale. Нестандартный
пользовательский title сохраняется.

## Не меняется

- одна общая ось X;
- unit bands;
- конверсия совместимых единиц;
- шкалы Y;
- custom legend;
- API;
- БД;
- config_json.
