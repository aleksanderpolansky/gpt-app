# ARCTor Dashboard Unit Bands V5

Дата: 2026-09-26

## Цель

Заменить V4-визуализацию, где каждая серия имела собственную скрытую Y-шкалу,
на единый многомерный временной график с понятными реальными шкалами.

## Визуальная модель

График остаётся одним аналитическим блоком.

- Ось X времени общая для всего блока.
- Подписи X показываются только один раз — под самой нижней зоной.
- Все зоны используют те же даты и одинаковые X-координаты.
- Вертикальная сетка выровнена между зонами.
- Recharts `syncId` + `syncMethod=index` синхронизируют наведение по дате.
- Между Y-зонами остаётся тонкая пустая/нейтральная разделительная полоса.

## Группировка

Отдельная зона создаётся не для каждой линии, а для семейства совместимых
единиц.

Первый реестр совместимости:

- duration: second / minute / hour / day -> preferred `minute`;
- mass: mg / g / kg -> preferred `kilogram`;
- distance: mm / cm / m / km -> preferred `meter`;
- volume: ml / l -> preferred `liter`;
- count -> `count`;
- presence -> `presence`;
- неизвестная единица образует собственную безопасную группу `unit:<code>`.

Несовместимые единицы никогда не конвертируются.

## Нормализация исходных фактов

До V5 аналитика требовала точного строкового совпадения единицы факта и
`canonical_unit_code` параметра. Поэтому факт `8 hour` не попадал в ряд
параметра с canonical unit `minute`.

V5 применяет универсальный линейный конвертер совместимых единиц:

`8 hour -> 480 minute`.

Это делается до обычной агрегации и до measurement rollup. Несовместимая
единица по-прежнему считается unit mismatch и не используется.

## Multi-series

Ответ multi-series нормализует числовые ряды в preferred unit их семейства и
добавляет `unitFamily`.

Например:

- Night sleep duration -> 480 minute -> family duration;
- Deep sleep -> 72 minute -> family duration;
- Awakening count -> 2 count -> family count.

Первые две линии рисуются в одной Y-зоне. Пробуждения — в другой.

## Шкалы

Для каждой зоны строится видимая Y-шкала.

- `count` использует целочисленные деления.
- Для `minute` выбирается удобный шаг 5/10/15/30/60/120/... минут.
- Для положительных данных шкала начинается с 0 и имеет небольшой запас сверху.
- Для прочих числовых единиц используется универсальный nice-step.

## Локализация

При локализации глобального ОН в analytics-data V5 передаёт `metadata_json`,
чтобы runtime localizations использовались не только в выборе ОН, но и в
легенде/графике.

## Совместимость

- БД и config_json не мигрируются.
- Существующий V4 `scaleMode=independent` остаётся читаемым как legacy config.
- Runtime V5 отвечает `layoutMode=unit_bands` и визуализирует старые и новые
  multi-series блоки одинаково.
- V3/V4 single-series и остальные аналитические блоки не меняются.
