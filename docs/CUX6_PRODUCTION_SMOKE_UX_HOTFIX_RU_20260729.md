# ARCTor.app — CUX6 Production Smoke UX Hotfix

Дата: 2026-07-29
Базовая точка: `main @ f0b74c17d5a3c333495d932d9ab47ff42bf362df`

## Причина

Production smoke подтвердил, что сама «Полка заданий» работает, но выявил три UX-недостатка:

1. Ссылка «Подробнее» открывала Activity Container вместо карточки активности с редактированием и отменой.
2. Внутренние группы сразу показывали карточки и постоянно занимали место.
3. Основная кнопка сохранения находилась внизу длинной формы быстрого добавления.

## Реализованный контракт

### 1. Одна ссылка на карточке задания

На карточке задания остаётся ровно одна ссылка «Подробнее».

Она открывает модальное окно в том же визуальном и поведенческом стиле, что карточка календарного мероприятия:

- данные активности;
- расписание;
- описание;
- статус, источник и приватность;
- кнопка «Контейнер активности» уже внутри popup;
- кнопка «Редактировать»;
- кнопка «Отменить активность».

Отдельная кнопка Activity Container непосредственно на карточке задания не добавляется.

### 2. Редактирование плановой активности

Редактор поддерживает:

- название;
- описание;
- без даты;
- только дату;
- диапазон дат;
- крайний срок;
- точное время;
- длительность для точного времени.

Изменение выполняется напрямую для канонической записи `activity_events` с обязательной проверкой владельца и активного профиля.

Для точного времени календарная проекция синхронизируется. Для неточных режимов возможная старая проекция отменяется. Новая дублирующая активность не создаётся.

### 3. Отмена задания

Отмена переводит каноническую плановую активность в статус `cancelled`. Связанная календарная проекция, если она существует, также отменяется.

Hard delete не выполняется.

### 4. Сворачивание внутренних групп

Вся «Полка заданий» остаётся видимой.

По умолчанию отдельно свёрнуты:

- «Без даты»;
- «Срок скоро»;
- «Нужно уточнение».

В свёрнутом состоянии видны:

- название группы;
- пояснение;
- количество;
- стрелка справа.

Каждая группа раскрывается и сворачивается независимо. Нижняя кнопка «Показать все» удалена.

### 5. Кнопка добавления активности

Кнопка «Добавить активность» перенесена в заголовок Quick Activity Entry рядом с кнопкой «Свернуть».

Нижний дубликат кнопки удалён. Существующие validation, idempotency, canonical POST и background semantic analysis не меняются.

## Граница этапа

Hotfix не меняет:

- системные или персональные AI-инструкции;
- алгоритм семантического различения «сделать до даты» и «начать в дату»;
- административное редактирование AI-скриптов;
- CUX7 Timeline/Gantt;
- структуру базы данных.

Редактор AI-скриптов остаётся отдельным комплексным этапом Master Plan v5.
