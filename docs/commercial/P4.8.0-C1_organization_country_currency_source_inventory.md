# P4.8.0-C1 — Organization Country/Currency Source Inventory

Status: INSPECTION-ONLY

Runtime code changed: NO

## 1. Purpose

Inspect where organization country, city and currency are currently represented in runtime routes and prepare a live DB check.

Business rule to preserve:

- one organization has exactly one country;
- international corporations register branches as separate organizations;
- organization currency is derived strictly from organization country;
- purchase confirmations, points thresholds and certificate calculations must use organization-derived currency;
- spent points for certificates are burned and are not transferred to seller.
