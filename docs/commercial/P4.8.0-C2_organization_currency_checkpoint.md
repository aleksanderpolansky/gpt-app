- offers use currency/certificate_currency/reference_currency, currently PLN/EUR pattern.

## 3. Current source-of-truth decision

For the current MVP:

- organization.country_code determines organization.default_currency.
- organization.default_currency is the stored organization currency.
- purchase_confirmations.purchase_currency should be derived from organization.default_currency.
- purchase_confirmations.currency is currently a duplicate/additive field and must not become a separate business source.
- offers.currency and certificates should stay aligned with organization.default_currency unless an explicitly approved exception is introduced later.

## 4. Future technical debt

- synchronization or consolidation of purchase_confirmations.purchase_currency and purchase_confirmations.currency;
- creation of commercial_currency_rules for 10 EUR equivalent threshold;
- explicit source-of-truth helper/service for country -> currency mapping;
- avoiding duplicated hardcoded currency mapping in several route files.
