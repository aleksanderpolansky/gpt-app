# P4.8.0-D2 — Shared Currency Helper Created

Status: HELPER CREATED / NOT ADOPTED BY ROUTES YET

Runtime behavior changed: NO

## 1. What was created

Created file:

- src/lib/commercial/currency.ts

The helper is isolated and not yet imported by existing runtime routes.

## 2. Purpose

The helper centralizes country/currency logic that was previously duplicated in route files.

It supports the current MVP rule:

- organization.country_code determines organization.default_currency.
- organization.default_currency is the stored organization currency.
- organization currency must not be arbitrary manual input.

## 3. Supported initial mapping

Initial mapping reflects current runtime behavior:

- PL -> PLN
- ES -> EUR
- DE -> EUR
- UA -> UAH
- US -> USD
- GB -> GBP
- CZ -> CZK

## 4. Functions added

- normalizeCountryCode
- normalizeCurrencyCode
- getDefaultCurrencyByCountryCode
- getOrganizationCurrency
- isOrganizationCurrencyDerivedFromCountry
- calculatePointsToSpendForCertificate
- getSupportedCountryCurrencyPairs

## 5. Certificate points rule

The helper includes the calculation rule for points spent on certificates:

- amount covered by points in organization currency divided by exchange rate equals raw points.
- points are rounded up with Math.ceil.
- spent points are burned and are not transferred to seller.
