# P4.8.0-D3.4 — Shared Helper Adopted in Organization Routes

Status: RUNTIME PATCH LIMITED TO ORGANIZATION ROUTES

## 1. Files changed

Runtime files changed:

- src/app/api/organizations/route.ts
- src/app/api/organizations/[id]/location/route.ts

Documentation file created:

- docs/commercial/P4.8.0-D3.4_shared_helper_adopted_in_organization_routes.md

## 2. What changed

Both organization routes now import:

- getDefaultCurrencyByCountryCode
- normalizeCountryCode

from:

- "@/lib/commercial/currency"

Local duplicated functions were removed from both organization routes.

## 3. Behavior preservation

D3.2 found that the old local route helper returned PLN as fallback for unsupported/unknown country codes.

D3.3 added explicit fallback support to the shared helper.

D3.4 preserves old behavior by calling:

- getDefaultCurrencyByCountryCode(locationInput.countryCode, { fallbackCurrency: "PLN" })

## 4. Scope limitation

Only organization routes were changed.

Not changed:

- directory routes;
- offers route;
- purchase confirmation routes;
- certificates;
- points logic;
- database schema.

## 5. Business rule preserved

This patch removes duplication without changing business behavior.

The later business-alignment block may remove legacy PLN fallback and enforce supported country/currency derivation explicitly.

## 6. Forbidden changes remain forbidden

- Do not add purchase_confirmation_items.
- Do not add purchase_confirmations.offer_id.
- Do not add purchase_confirmations.value_object_id.
- Do not turn purchase confirmation into cart/order/item flow.
- Do not let organization currency become arbitrary manual user input.
- Do not transfer burned points to seller.
- Do not bypass certificate/points RPC.
