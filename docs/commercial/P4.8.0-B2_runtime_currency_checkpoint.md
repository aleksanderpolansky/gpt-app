## 3. Corrected business decisions

- Currency logic is already solved conceptually.
- Each organization has exactly one country.
- Organization currency is derived strictly from country.
- International corporations must register country branches as separate organizations.
- Purchase confirmation currency should be derived from organization currency.
- Minimum purchase threshold for awarding 10 points should be based on 10 EUR equivalent in organization currency.
- Threshold rules should be platform-level country/currency rules, not per-organization arbitrary settings.

## 4. Burned points rule

- Points spent by a buyer on a certificate are burned.
- The seller does not receive those points.
- The seller receives only the money part of the certificate payment.
- Points act as discount/reduction rights, not as transferable currency.

## 5. Technical debt / later alignment
