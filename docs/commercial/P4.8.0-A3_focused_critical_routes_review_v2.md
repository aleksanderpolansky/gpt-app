Runtime code changed: NO

Why v2 exists: dynamic Next.js route folders like [id] and [slug] must be checked with PowerShell -LiteralPath. Without it, Test-Path can return false because square brackets are treated as wildcard syntax.

Purpose: focused manual review input for P4.8.0-A4 relationship gap analysis.

Target architecture decisions:

- Value Object is unified for personal and enterprise scenarios.
- Offer is not Value Object; offer is certificate terms / commercial package.
- Certificate must be created from offer.
- Purchase confirmation is organization-level external purchase confirmation, not cart/order/item flow.
- Points must remain ledger-style; no manual balance mutation.
