## 3. Current source-of-truth decision

For the current MVP:

- organization.country_code determines organization.default_currency.
- organization.default_currency is the stored organization currency.
- purchase_confirmations.purchase_currency should derive from organization.default_currency.
- purchase_confirmations.currency is currently duplicate/additive and must not become a separate business source.
- offers.currency and certificates should stay aligned with organization.default_currency unless a separate approved exception is introduced later.

## 4. Minimum purchase threshold finding

C3 confirmed that src/app/api/directory/organizations/route.ts already contains route-local MINIMUM_PURCHASE_THRESHOLDS.

Interpretation:

- 10 EUR equivalent threshold logic is partially represented.
- It is currently hardcoded and route-local.
- It should later move to a platform-level rules model such as commercial_currency_rules.
