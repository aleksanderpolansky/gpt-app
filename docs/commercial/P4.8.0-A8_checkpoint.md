## 4. Confirmed architecture decisions

- Value Object is the unified value entity.
- Offer is not a Value Object.
- Offer may have internal offer_items package/composition.
- offer_items is not purchase confirmation items.
- Certificate is created from Offer.
- Purchase confirmation is organization-level external purchase confirmation.
- No purchase_confirmation_items.
- No purchase_confirmations.offer_id.
- No purchase_confirmations.value_object_id.
- No cart/order/item flow for purchase confirmations.
- Points and certificates remain RPC/ledger-sensitive.
