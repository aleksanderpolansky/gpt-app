# P4.9.2-A2 — value_object_category_links runtime integration plan

Date: 2026-05-18
Status: READY FOR CODE CHANGE

## Purpose

Connect value_object_category_links from reliable category/rubricator mapping metadata.

## Integration point

Use the same proven hot path:

- lib/activity/valueObjectBridge.ts

This file already has:

- event.id
- event.user_id
- mapping.valueObjectId
- mapping.metadata
- old VOI link id
- new p491 activity_event_value_object_links id
- processorName
- confidence
- source

## New helper target

Add an additive helper that upserts into:

- public.value_object_category_links

## Source of category data

Use:

- mapping.metadata.classification.contextualCategoryId
- mapping.metadata.classification.contextualCategorySlug
- mapping.metadata.classification.contextualCategoryName
- mapping.metadata.classification.classificationRole
- mapping.metadata.controlledRule
- mapping.metadata.mapper
- mapping.metadata.mapperVersion

## Upsert key

Use existing DB unique key:

- value_object_id
- category_table
- category_id
- category_role

## Target row fields

- value_object_id = mapping.valueObjectId
- category_table = contextual_categories
- category_id = classification.contextualCategoryId
- category_role = primary when classificationRole is primary, otherwise semantic_component
- source = normalized v4.2 source
- confidence = mapping confidence
- metadata_json.p492.mode = runtime_category_link_from_bridge_mapping_metadata
- metadata_json.p492.sourceEventId = event.id
- metadata_json.p492.sourceProjectionId = activity_event_value_object_links.id when available

## Compatibility rules

Do not:

- replace existing VOI pipeline
- change relation_type logic
- change value_object_instances
- change value_object_state_deltas
- change value_object_daily_aggregates
- change value_object_state_snapshots
- introduce tags/entity_tags
- create typed relation edges

## Error handling

If category link upsert fails:

- do not roll back old VOI pipeline
- do not fail the whole bridge result
- store the category-link error on createdItem
- console.warn for diagnostics
