7. What this proves

This proves that the system can automatically derive additional semantic candidates from a user activity text without manually creating the activity categories each time.

The proven mechanism is:

user activity text
->
deterministic extractor
->
candidate slugs
->
semantic layers such as action, domain, participant, purpose, care_function, duty, ambiguity_marker

This is not a final universal taxonomy.

It is a small benchmark proving that the Category Derivation Layer can detect deeper role/care/purpose semantics.
