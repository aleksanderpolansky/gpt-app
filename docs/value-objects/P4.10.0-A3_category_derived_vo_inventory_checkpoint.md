## v4.2 guardrails for the next block

- Global category is not the same as personal/enterprise Value Object.
- Value Object is derived from category or category combination.
- Activity Event stores real time once.
- Event -> ValueObject links provide exposure_minutes.
- Analytical exposure time may exceed 24 hours.
- MVP relation model remains parent/child only.
- Do not introduce typed relation edges now.
- Do not introduce tags/entity_tags now.
- Do not introduce full UX/UI now.
- Do not introduce external API/calendar/wearable/NFC now.
