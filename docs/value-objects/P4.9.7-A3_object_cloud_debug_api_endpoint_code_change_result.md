## Purpose

Expose the reusable object-cloud read interface through a read-only debug API endpoint.

## Source view

- public.value_object_cloud_profiles_v1

## Auth/session convention

The endpoint follows the existing project convention from src/app/api/value-objects/route.ts:

- auth0.getSession()
- app_users lookup by auth0_sub
- Supabase service client from lib/supabase

## Supported query params

- categorySlug
- valueObjectId
- limit

## Response sections

- filters
- counts
- categorySummary
- latestObjects
- profiles

## Read-only rule

The endpoint only reads from public.value_object_cloud_profiles_v1.

It does not write to:

- activity_event_value_object_links
- value_object_usage_aggregates
- value_object_category_links
- value_object_state_deltas
- value_object_daily_aggregates
- value_object_state_snapshots

It does not modify valueObjectBridge.ts or the old VOI pipeline.
