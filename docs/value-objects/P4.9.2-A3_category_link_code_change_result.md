## What changed

## New behavior

After the existing VOI link succeeds and after the already verified p491 projection helper runs, the bridge now attempts to upsert a Value Object category link from reliable rubricator/classification metadata.

## Error handling

If value_object_category_links upsert fails, the bridge logs a warning and records the error on createdItem.valueObjectCategoryLinkError, but it does not roll back the existing VOI pipeline or the p491 projection layer.
