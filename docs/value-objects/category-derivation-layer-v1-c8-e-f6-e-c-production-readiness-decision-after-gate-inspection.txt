5. Why this is a hard gate

production_persist can create durable category_derivation_runs and activity_category_derivations rows.

If routeRunner does not use completed-run lookup/idempotency protection, repeated completions or retries may create:

- duplicate derivation runs for the same activity event;
- duplicate activity_category_derivations rows;
- inconsistent routeRunner state;
- difficult cleanup/rollback requirements;
- misleading analytics;
- incorrect confidence in production-readiness.

Therefore production_persist must not be enabled directly.
