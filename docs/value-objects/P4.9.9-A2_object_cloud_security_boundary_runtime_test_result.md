## Remaining architectural warning

If lib/supabase.ts uses SUPABASE_SERVICE_ROLE_KEY, RLS is bypassed at the database layer.

Therefore the TypeScript user_id filter remains the main ownership boundary for this debug endpoint.

For production/non-debug exposure, this route should either:

1. receive an explicit admin/dev-only guard, or
2. be moved to an RLS-respecting user-scoped Supabase client pattern.
