TARGET ARCHITECTURE FOR CATEGORY DERIVATION LAYER V1

The target pipeline is:

raw Activity Event
-> pre-processing / normalization
-> category_derivation_run
-> rule-based categoryCandidates
-> optional AI structured classifier behind feature flag
-> candidate merge
-> resolver / governance
-> activity_category_derivations
-> Value Object Bridge handoff
-> value_object_category_links
-> activity_event_value_object_links
-> aggregates / snapshots
-> proof routes / benchmark records
-> Semantic Capital records

The key principle:
AI output is not truth.
AI output is a versioned interpretation that must be persisted, resolved, governed, and corrected.

REQUIRED SEMANTIC LAYERS

The category bundle should support:
- action
- object / domain
- participant
- relationship_context
- role
- duty / responsibility
- care_function
- purpose / activity_meaning
- metric
- state / context hooks for future next-best-action logic
