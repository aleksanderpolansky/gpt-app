============================================================
2. Seed list rules
============================================================

This seed list must follow the D3-A governance rules:

1. Do not create medical facts.
2. Do not create hormonal conclusions.
3. Do not create psychological diagnoses.
4. Do not create confirmed business outcomes.
5. Do not create user state facts.
6. Do not create Value Object subtypes.
7. Do not modify the unified Value Object model.
8. Use safe proxy wording.
9. Mark sensitive dimensions clearly.
10. Keep default_privacy_level = private for all initial seed dimensions.
11. Prefer proxy_only, system_estimate, or user_confirmed.
12. Avoid direct_measurement unless the source is actually measurable.
13. Use blocked only for future forbidden dimensions, not in the first active seed.
