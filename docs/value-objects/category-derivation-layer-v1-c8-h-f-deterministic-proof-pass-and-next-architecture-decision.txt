9. Why state layers are not started yet

State layers should not be implemented directly on top of raw extractor output.

A future state engine needs stable, persisted and reviewable semantic facts.

Before state engine implementation, the system needs to know:

- which candidates are deterministic
- which candidates are AI-suggested
- which candidates are resolved to controlled categories
- which candidates are working drafts
- which candidates require user review
- which candidates are revoked or corrected
- which candidate version created which downstream VO link or snapshot
- whether a state signal is direct, inferred, possible or contraindicated

Without this, state snapshots could overclaim fatigue, stress, focus, income-generation, customer responsibility, care load or next-best-action relevance.
