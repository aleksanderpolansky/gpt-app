## Final decision

The object-cloud debug stack remains a debug/admin tool.

It is now protected against accidental production exposure by an explicit guard.

## Current production behavior

In production, the debug endpoint is blocked unless:

- VALUE_OBJECT_CLOUD_DEBUG_ENABLED=true

## Current local behavior

In local development, the debug endpoint remains available because:

- NODE_ENV is not production

## Important rule going forward

Do not add /value-objects/debug/cloud-profile to normal public navigation.

Use it as a developer/debug page only.
