# P4.9.10-A2 — object-cloud debug exposure guard code change result

Date: 2026-05-18
Status: CODE WRITTEN / READY FOR TYPECHECK AND RUNTIME TEST

## Purpose

Add an explicit debug exposure guard for:

- /api/value-objects/debug/cloud-profile

## New helper

- lib/value-objects/objectCloudDebugGuard.ts

## Updated endpoint

- src/app/api/value-objects/debug/cloud-profile/route.ts

## Guard rule

The endpoint is allowed when:

1. NODE_ENV is not production, or
2. VALUE_OBJECT_CLOUD_DEBUG_ENABLED is explicitly true.

Otherwise the endpoint returns:

- HTTP 403
- ok: false
- error: Value Object cloud debug endpoint is disabled.

## Why this guard was added

P4.9.9 confirmed that the object-cloud debug endpoint is safe for hidden/debug usage but should not be exposed as a normal production feature yet.

The shared Supabase client may use service-role credentials, so this endpoint now has an explicit production/debug gate.

## Expected local behavior

Local development should continue to work because NODE_ENV is not production.

## Expected production behavior

Production should block access unless:

- VALUE_OBJECT_CLOUD_DEBUG_ENABLED=true
