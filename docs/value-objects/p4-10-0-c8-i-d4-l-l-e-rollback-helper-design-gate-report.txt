Transaction strategy decision:
ATOMIC_RPC_REQUIRED_BEFORE_RUNTIME_ROLLBACK

Decision:
Do not implement rollbackStateFactControlled as a non-atomic Supabase JS two-step sequence.

Reason:
Rollback must update value_object_state_facts and insert value_object_state_fact_audit_events as one atomic unit. A non-atomic Supabase JS two-step update + insert can leave the system inconsistent if the first write succeeds and the second fails.

Rejected strategy:
1. Update value_object_state_facts with Supabase JS.
2. Insert value_object_state_fact_audit_events with Supabase JS.
3. Treat both as one logical rollback.

Why rejected:
- The two writes would not be guaranteed atomic at the application helper level.
- If the state fact update succeeds and the audit insert fails, rollback becomes under-audited.
- If the audit insert succeeds and the state fact update fails, rollback becomes falsely audited.
- Idempotency cannot fully repair partial-write ambiguity without a transaction boundary.
- The whole C8-I/D4 governance line requires auditable and controlled persistence.

Selected strategy:
Design a narrow Postgres RPC/stored function before runtime rollback.

Required future RPC characteristics:
- Narrow scope: rollback exactly one state fact.
- Inputs must include at minimum:
  - p_user_id
  - p_value_object_id
  - p_state_fact_id
  - p_reason
  - p_request_trace_id
  - p_idempotency_key
  - p_source_route
  - p_helper_version
  - p_contract_version
  - p_d4_gate_version
  - p_rollback_at
  - p_actor_id, nullable
  - p_evidence_json, nullable/default
  - p_metadata_json, nullable/default
- Must update value_object_state_facts only with:
  - correction_status = 'rolled_back'
  - valid_to = rollback timestamp
  - metadata_json merged/extended with rollback metadata
  - updated_at = rollback timestamp
- Must insert value_object_state_fact_audit_events in the same transaction.
- Must enforce idempotency using value_object_state_fact_audit_events_idempotency_uq.
- Must never delete a state fact.
- Must never authorize by state_fact_id alone.
- Must include value_object_id in target matching.
- Must return a small structured result.
