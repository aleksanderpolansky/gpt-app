# ARCTor Local XLSX Editor V1.3 — новая книга, листы и массовая структура

Дата: 2026-08-30
Baseline: b8a191b4c711d287e11791ba091ac10103676bb0
Release: ARCTOR_LOCAL_XLSX_EDITOR_V1_3_BLANK_WORKBOOK_SHEETS_BULK_STRUCTURE

## Что добавлено

1. В карточке XLSX появился запуск новой пустой книги без загрузки исходного файла.
2. Новая книга создаётся только в памяти браузера через SheetJS и получает первый лист Sheet1.
3. В редакторе можно добавлять новый лист, переименовывать активный лист и удалять активный лист.
4. Имя листа валидируется по ограничениям Excel: 1–31 символ, запрещены : \ / ? * [ ], дубликаты без учёта регистра запрещены.
5. Последний лист удалить нельзя.
6. Переименование и удаление листов блокируются для книг с формулами, merge, filters или named ranges, чтобы не ломать ссылки. Добавление нового листа остаётся безопасно доступным.
7. Для операций строк/столбцов добавлен выбор количества от 1 до 50. Одна операция создаёт одну запись Undo/Redo.
8. Массовая операция атомарна: если весь диапазон удалить/изменить нельзя, исходный лист восстанавливается.
9. Изменение структуры листов очищает старую Undo/Redo-историю и сохраняет базовый dirty-state; последующий Undo изменения ячейки не может ошибочно объявить книгу сохранённой.
10. Карточка локального XLSX больше не показывает устаревший текст о будущем движке — указывает, что редактор активен.

## Privacy boundary

- новый XLSX создаётся client-side;
- содержимое книги не отправляется в API ARCTor;
- server storage: 0;
- SQL: 0;
- migrations: 0;
- persistent browser document storage: 0.

## Acceptance

- «Новая пустая таблица» открывает Sheet1 и помечается как несохранённая до первого локального сохранения.
- «Новый лист» создаёт Sheet2/Sheet3 и переключает редактор на него.
- переименование принимает корректное уникальное имя и отклоняет запрещённое/дублирующееся.
- последний лист удалить нельзя.
- количество 5 + «вставить строку выше» вставляет пять строк относительно выбранной ячейки одним Undo.
- количество 5 + «вставить столбец справа» вставляет пять столбцов справа от выбранной ячейки одним Undo.
- неудачная массовая операция не оставляет частично изменённый лист.
- сохранённый новый файл повторно открывается как обычный XLSX.
