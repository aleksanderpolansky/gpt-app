# ARCTor Local XLSX Editor V1.3.1 — редактирование пустых ячеек

Дата: 2026-08-31
Baseline: dee59e82d65797fcdbbba07ac876ebc46d83835b
Release: ARCTOR_LOCAL_XLSX_EDITOR_V1_3_1_BLANK_CELL_EDIT_HOTFIX

## Причина hotfix

После V1.3 управление листами работало, но в новой пустой книге на desktop редактирование пустой ячейки не запускалось предсказуемо при включённом range selection. Tabulator рекомендует при range selection задавать editTriggerEvent явно как click или dblclick, вместо значения focus по умолчанию.

## Решение

- В XLSX-редакторе desktop editTriggerEvent явно установлен в dblclick.
- Один клик остаётся выбором ячейки для структурных операций.
- Двойной клик или Enter по выбранной ячейке запускает редактор.
- На compact touch/mobile существующая обвязка ArctorTabulator по-прежнему переопределяет trigger на click.
- Privacy boundary не меняется.

## Acceptance

1. Создать новую пустую таблицу.
2. Один клик по C5 меняет выбранную координату на C5 без принудительного открытия редактора.
3. Двойной клик по C5 открывает поле ввода; после ввода текст виден в C5.
4. Выбрать C5, вставить строку выше/ниже и столбец слева/справа — значение смещается вместе с ячейкой.
5. Undo/Redo восстанавливает значение и структуру.
6. На смартфоне один тап продолжает открывать редактор.

## Точка продолжения

После production acceptance V1.3.1 закрыть V1.3 и перейти к V1.4 форматирования.
