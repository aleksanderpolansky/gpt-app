RECURRENCE
----------
The recurrence source/definition is a pattern and cannot be completed.

Project source card:
editable=YES
completable=NO

Materialized occurrence:
editable=YES
completable=YES

Server API rejects completion of an active/paused recurrence definition
with RECURRENCE_DEFINITION_NOT_EXECUTABLE.

Editing result options on the recurrence source propagates those options
to active/rescheduled already-materialized occurrences.

Future occurrences inherit source metadata through the existing
recurrence materializer.
