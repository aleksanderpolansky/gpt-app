PROBLEM
-------
Actor-owned leaf Observation Objects may have a global system intermediate
Observation Object as their direct structural parent.

Example:

Actions and Processes
  -> Nutrition and consumption
       -> Organization of nutrition       actor/private leaf
       -> Restaurant visits               actor/private leaf

The previous actor-owned detail read path obtained the actor tree separately.

Therefore parent_value_object_id could correctly point to:

Nutrition and consumption

while that global system node was absent from the actor-only nodesById map.

Visible symptoms:

Top "Position in structure":

Root:
Restaurant visits

Structural parent:
—

Path:
Restaurant visits

while canonical ontology data below correctly contained:

Structural parent:
Nutrition and consumption

Root:
Actions and Processes

A second symptom was mixed localization:

Russian page UI
but system parent/root titles could appear in canonical English.

DECISION
--------
Do not patch only the single actor-leaf -> global-parent case.

Use one mixed read model for the complete branch:

GLOBAL SYSTEM NODES
+
PRIVATE NODES OF CURRENT ACTIVE USER/ACTOR

This supports:

global root
 -> global intermediate
     -> global intermediate
         -> global leaf
         -> actor/private leaf
     -> global leaf
     -> actor/private leaf

No separate ontology model is introduced.

MIXED TREE READER
-----------------
Added:

src/lib/reality-core/mixed-value-object-tree-read.server.ts

The reader loads:

1. global/system_model nodes for the requested root;
2. actor-scope nodes belonging only to:
   current appUserId + current actorId.

They are merged by canonical Value Object id.

GLOBAL LOCALIZATION
-------------------
Every global/system_model node is localized with the existing:

localizeGlobalSystemValueObject

No new global localization mechanism was introduced.

ACTOR LOCALIZATION
------------------
Actor-owned node titles use the existing read-only resolver:

resolveActorValueObjectReadLocalizationsV1

No AI translation generation and no localization write occurs during read.

PRIVACY
-------
Actor nodes are explicitly restricted by:

owner_user_id = current app user
owner_actor_id = current active actor

Private Observation Objects belonging to other users or actors are not merged
into the mixed tree.

CROSS_USER_PRIVATE_READ=NO

VALUE OBJECT DETAIL
-------------------
/value-objects/[id] now uses the mixed reader for tree/path construction.

Therefore the following all use the same mixed graph:

parentNode
pathNodes
rootTitle
parentTitle
pathText
directChildren
siblings
descendant tree

This is valid for both:

- a global/system Observation Object page;
- an actor/private Observation Object page.

ONTOLOGY CARD API
-----------------
/api/value-objects/ontology/[id]

now localizes a mixed ontology card according to each node's origin:

global/system node
  -> global system localization

current actor/private node
  -> actor localization

This fixes the lower semantic card as well as the top structure presentation.
