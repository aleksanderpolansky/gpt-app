SEMANTIC CONTRACT
-----------------
activity_events remains the canonical activity entity.
No project_tasks or todo_tasks entity was introduced.

Planned work:
activity_role_code=planned

Completion:
creates a separate activity_event with
activity_role_code=actual
status=completed

Plan -> Actual:
fulfills_planned_activity_event_id

Undo:
does not delete the actual event.
The completion actual event is changed to status=cancelled.

PROJECT MEMBERSHIP
------------------
Completed actual activity inherits active project_activity_links
from the planned activity.

Project API displays only planned top-level project cards,
so inherited actual membership does not create a duplicate task card.

RECURRENCE
----------

Materialized occurrence is the actionable planned activity.
Completed occurrence disappears from the active task list.
Completed occurrence disappears from project upcomingOccurrences.
Future recurrence occurrences remain independent.
