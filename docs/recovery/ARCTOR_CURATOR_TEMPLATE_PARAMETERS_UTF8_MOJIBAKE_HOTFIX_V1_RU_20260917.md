## Причина

В исходном файле:

src/app/admin/reality-curator/signals/curator-template-parameters.tsx

локализованные строки уже физически находились в состоянии
UTF-8 bytes interpreted/stored through Windows-1252.

Это UI/source encoding defect.

Данные Supabase не повреждены.

E01 mappings не повреждены.

E02 migration не повреждена.

## Исправление

Выполнено строгое обратное преобразование:

Windows-1252 code points
→ исходные UTF-8 bytes
→ корректный Unicode.

Файл сохранён как UTF-8 without BOM.

Перед записью проверено наличие ожидаемого corruption pattern.

После преобразования проверены контрольные строки:

- Параметры типовой активности
- Выбранные параметры
- Объект наблюдения для измерения определён
- Объекты наблюдения для измерения определены для всех параметров

Также проверено сохранение E02 integration:

CuratorSystemTemplateMaterialization.
