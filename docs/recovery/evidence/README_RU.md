# Evidence

Здесь хранятся читаемые первичные отчёты ключевых шагов.

Правило:

- сохраняем REPORT.txt и необходимые диагностические JSON;
- большие PACKAGE.zip не обязаны храниться в Git;
- если PACKAGE нужен позже, его можно отдельно скачать/сохранить, но человеческая история не должна зависеть от наличия ZIP;
- каждый скопированный evidence-файл индексируется в `EVIDENCE_INDEX.json` с SHA-256.

Скрипт первого recovery snapshot ищет в `Downloads` последние REPORT-файлы известных GSR1G/GSR1H/GSR1I шагов и копирует найденные.
