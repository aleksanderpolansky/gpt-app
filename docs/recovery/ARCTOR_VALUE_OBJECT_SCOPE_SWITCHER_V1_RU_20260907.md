# ARCTOR_VALUE_OBJECT_SCOPE_SWITCHER_V1 — recovery checkpoint

Дата: 2026-09-07

## Цель

Добавить на `/value-objects` единый верхний переключатель области каталога в визуальном стиле переключателя сертификатов: «Мои объекты наблюдения / Системные объекты наблюдения / Все объекты наблюдения».

## Архитектурное решение

- API и БД не меняются: `/api/value-objects` уже возвращает глобальные системные ОН и ОН активного профиля.
- Область каталога — отдельный фильтр более высокого уровня, чем структурные фильтры «Все / Корни / Промежуточные / Листы / Черновики».
- `scope=mine` показывает только ОН текущего профиля; `scope=system` — только глобальные системные ОН; `scope=all` — объединённый каталог.
- Значение `scope` сохраняется в URL, поэтому поддерживаются обновление страницы, ссылки и Back/Forward.
- Счётчики, поиск, дерево, карточки, карта, таблица и итог «Показано X из Y» считаются от выбранной области каталога.
- По умолчанию используется `scope=all`, то есть прежнее поведение сохраняется.
- Переключатель повторяет уже используемый стиль сертификатов: белый контейнер с рамкой и `p-1`, активная синяя кнопка, неактивные прозрачные кнопки.
