# M-0136 / ARI-03.07.05 — Timeout, Circuit Breaker, Lexical Read-Only Fallback

Мастер-план: «Добавить timeout/circuit-breaker/fallback на lexical read-only». Режим CODE.

В `indexLifecycleV1.ts` добавлена `createIndexReadFallbackV1()`: исполняемый контроллер с внедряемыми только read-only адаптерами. Защита по умолчанию требует `vectorReadApproved=true`, `fresh` индекс и предварительную проверку доступа M-0134.

- Тайм-ауты обоих чтений, сигнал отмены и отбрасывание запоздавших результатов.
- Порог ошибок, открытая цепь, период охлаждения, единственная half-open проба в рамках одного контроллера.
- Изоляция состояний по пользователю и конкретному индексу.
- На ошибке вектора переходит к лексическим кандидатам, сохраняя read-only и проверяя принадлежность/версии всех ОН.
- Ошибки резервного поиска и чужие/некорректные результаты приводят к отказу без утечки данных.
- 7 локалей. Новый тестовый набор: 105 случаев.
- Ни один из методов не инициирует SQL, изменение индекса, генерацию embeddings или платные API-вызовы.

**Ограничения:** контур circuit breaker находится в памяти отдельного процесса, не координируется между разными инстансами. AbortSignal не может гарантировать остановку уже начатой операции в стороннем адаптере. Подключение к API и реальные проверки RLS/GRANT ещё не проводились; M-0137 и дальнейшие шаги запланированы отдельно. Поэтому использовать только read-only non-billable adapters.

Предыдущие M-0132—M-0135 остаются без изменений.
