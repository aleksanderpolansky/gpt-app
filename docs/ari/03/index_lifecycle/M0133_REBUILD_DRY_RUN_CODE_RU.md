# ARCTor / M-0133 / ARI-03.07.02 — Dry-run index rebuild и preview изменённых ОН

**Режим по мастер-плану: CODE.** Задача: «Разработать dry-run index rebuild с preview числа изменённых ОН».

## Что реализовано

Дополнение к `src/lib/ontology-research/indexLifecycleV1.ts`, которое предоставляет чистую функцию `previewIndexRebuildV1(record, publishedSource, desiredSource)` и версионированный контракт `ARCTOR_ARI03_INDEX_REBUILD_PREVIEW_V1`.

- Сверяет актуальный `source_hash` из M-0132 с целевым снимком и `published_source_hash` с опубликованным снимком.
- Считает **добавленные, изменённые, удалённые и неизменённые ОН** по UUID, а также точные изменения единиц `UUID + locale`.
- Рассчитывает количество embeddings для обновления как сумму добавленных и изменённых единиц. Удаления ничего не векторизуют.
- Для 7 языков допускает изменение одного языка без перерасчёта прочих неизменившихся единиц того же ОН.
- При несовпадении владельца, области, модели, версии, исходного хеша или отсутствии обязательного опубликованного снимка **отклоняет расчёт**.
- Для индекса со статусом `building` рекомендует дождаться текущего процесса; при `fresh` и неизменённом снимке рекомендует не перестраивать.
- Результат содержит `dry_run=true`, `writesPerformed=false`, `paidCallsPerformed=false`, `sqlExecuted=false`, `indexRebuilt=false`, `approvalGranted=false` и `aclVerified=false`.

## Границы шага

Это предварительный расчёт **по предоставленным валидированным снимкам**, а не запуск задания перестроения. Модуль не вызывает внешние API, не обращается к Supabase и не создаёт реальные embeddings. Система хранения и приёмника snapshots должна быть подключена в соответствующих последующих шагах. Изоляция прав ACL — M-0134; реплей при ошибках — M-0135; circuit breaker/fallback — M-0136; RLS/GRANT — M-0137.

## Тесты и критерий завершения

86 новых тестов и 1980 повторно выполняемых предыдущих тестов, итого **2066 PASS** и TypeScript strict без ошибок. Демонстрационная последовательность `initial → published → changed` из трёх ОН подтверждает корректность preview. Шаг принимается только после явного подтверждения владельца и пересчёта приватного журнала в правильной строке M-0133.
