# ARCTor M-0112 — нормализация алиасов с учётом языка

Основание: утверждённая дорожная карта `ARI-03.04.02` (M-0112): «Добавить locale-aware normalizer без разрушения польских и чешских диакритик».

## Цель и границы

Изменяется только `src/lib/ontology-research/localeAliasIndexV1.ts`, добавляется `scripts/tests/ari03-m0112-locale-normalizer.test.cjs`. Модуль остаётся чистой локальной функцией поверх **предварительно авторизованного** списка источников и проверенных человеком алиасов. Интерфейсы, базы, сетевые сервисы и существующие API не меняются. Существующая однопараметрическая `normalizeAliasKeyV1(text)` сохранена.

## Правила нормализации

- 7 локализаций: en, pl, es, de, cs, uk, ru.
- Unicode `NFKC` + языково-зависимый lower-case + `NFC` + сворачивание пробельных последовательностей.
- **Не удаляются** польские и чешские диакритики (`ł`, `ż`, `č`, `ě`, `ů`), испанское `ñ`, немецкое `ß`, украинские `ґ`, `ї`, русская `ё`.
- Для украинского только символы типографского апострофа `’` (U+2019) и `ʼ` (U+02BC) приводятся к ASCII `'`. Апостроф не удаляется.
- НЕ делаем stemming, транслитерацию, автоэквивалентность ё/е, перевод, выбор UUID или разрешение создания ОН.
- Разные UUID с одним ключом — `ambiguous`, а не автоматическое объединение.
- `absenceProven = false` независимо от ответа.

- SQL/AI/API/commit/push/deploy: НЕТ. Live database UUID binding, privacy E2E и включение нового поиска: НЕ подтверждаются.
