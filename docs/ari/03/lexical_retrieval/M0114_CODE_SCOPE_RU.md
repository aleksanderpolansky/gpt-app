# M-0114 / ARI-03.04.04 — омонимы, многозначность и неопределённость

## Объём
- В `src/lib/ontology-research/localeAliasIndexV1.ts` добавлен `buildLocaleSenseIndexV1` и типизированные структуры проверенных смысловых признаков. Прежние `buildLocaleAliasIndexV1`, `buildBroaderNarrowerIndexV1`, `normalizeAliasKeyV1` сохраняются.
- Каждый кандидат хранит UUID ОН, `senseKey`, язык, словоформу, проверенные положительные/отрицательные подсказки и проверяемое происхождение (тип, источник, версия, SHA-256).
- Одинаковое слово с разными `objectId` / `senseKey` возвращает `status=unresolved` и весь набор кандидатов. Контекст лишь указывает совпавшие признаки; `autoSelectedId=null` при любом исходе.
- Одна проверенная трактовка возвращает `review_required`; ноль проверенных — `no_verified_sense` и `absenceProven=false`. Никаких разрешений на создание ОН.
- Тесты: 80 новых на семи языках с омонимами en bank, pl zamek, es banco, de Bank, cs zámek, uk ключ, ru лук; 352 прежних M0104–M0113.

## Границы
Без внешних словарей, морфологического разбора, назначения смыслов живым ОН, индексов и SQL. Синтетические UUID и признаки демонстрируют контракт, не реальные связи каталога. Никакая новая запись не попадает на сайт до отдельной интеграции и E2E. Не принимаем достоверность примеров за медицинские/социальные знания.

## Безопасность
Входные данные предварительно отфильтрованы по правам серверным вызывающим кодом; этот модуль сам не проверяет RLS и не делает сетевых запросов. Проверены блокировка невалидных источников, недопустимых ключей, коллизий, дубликатов, пределы входа и копирование доказательств. `broader_narrower` не преобразуется в синоним.
