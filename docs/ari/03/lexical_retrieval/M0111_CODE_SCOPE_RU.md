## Предметная граница и доказательства
`M0111_SOURCE_INVENTORY.json` содержит 14 слов (по два для каждого из EN, PL, ES, DE, CS, UK, RU). Исходные написания проверяются тестами непосредственно против словаря `src/lib/ontology-research/ari02EnhancedSearch.ts` текущего репозитория. Это **верификация фактического наличия в кодовом источнике**, но ещё НЕ доказательство, что любой перевод уже утверждён куратором как алиас конкретного существующего ОН с конкретным UUID.

Индекс принимает только явно переданные записи с UUID, источником с SHA-256, версией, статусом `verified` и идентификатором рецензента. Эти `verified`-записи демонстрируются на **синтетических UUID в тестах**; реальные UUID из базы не выдумываются, соответствия между переводами и реальными ON не записываются и не сертифицируются.

## Проверяемые инварианты
- Семь поддерживаемых локализаций: EN, PL, ES, DE, CS, UK, RU.
- Подтверждённые эквиваленты с одним UUID дают **одного кандидата**, а не клоны ОН.
- Коллизия разных UUID остаётся `ambiguous`, без автоматического объединения и выбора UUID.
- Неподтверждённые словарные источники не становятся рабочими алиасами.
- `autoSelectedId = null`, `absenceProven = false` для любого ответа.
- Нормализация на этом этапе консервативна, не стирает польскую/чешскую диакритику.
- Вызов строителя предполагает **заранее авторизованный набор**; этот модуль не заменяет RLS/приватный API.
