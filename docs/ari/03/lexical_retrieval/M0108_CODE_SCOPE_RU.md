# ARCTor M-0108 / ARI-03.03.05 — scoped query, limit и пагинация

## Соответствие дорожной карте
**Задание:** «Добавить scoped query и limit/pagination без скрытого truncation при проверке существования». Файлы проекта остаются в существующих каталогах: `src/lib/ontology-research/lexicalRetrievalV1.ts` и `scripts/tests/ari03-m0108-scoped-pagination.test.cjs`.

## Реализация
- Существующая функция `retrieveWeightedLexicalV1` принимает необязательные `offset` (0…2000) и `scopeMode` (`preauthorized_global` / `preauthorized_global_and_own`). Прежние вызовы без них работают как прежде.
- Ранжируются **все** переданные разрешённые кандидаты (не более 2000); затем выбирается страница (1…20). Отбрасывания кандидатов до ранжирования нет. Переполнение 2000 приводит к явной ошибке, а не к скрытому отсечению.
- Ответ содержит `page.offset`, `page.limit`, `page.returned`, `page.hasPreviousWithinInput`, `page.hasMoreWithinInput`, `page.nextOffset`, `page.totalMatchedWithinInput`, а также прежние `evaluated`, `totalMatched`, `truncated`.
- `scopeMode` — только метка, описывающая **подразумеваемую** область уже отфильтрованных сервером записей, а не авторизация. Модуль никогда не утверждает, что проверил RLS/ACL или весь каталог. В ответе `catalogCoverage=UNVERIFIED_INPUT_ONLY` и `absenceProven=false` при любом количестве совпадений.
- Неизвестные поля (`ownerId`, `actorId`, `includePrivate`, `cursor`), недопустимые страницы и области отвергаются. Пагинация допускается только по повторной оценке одного и того же набора разрешённых кандидатов; стабильность между изменениями каталога и криптографическая защита cursor здесь не заявляются.
- Алиасы с неподтверждёнными целевыми ОН не используются; историческая проблема M-0091 (89/89) остаётся открытой.

## Границы M-0108
**Не создаём** новые страницы, API, БД/RPC, индексы, миграции, новые поисковые системы и привилегии доступа. Не выполняем commit, push или deployment. Проверка реального server-side actor filter и связывания со снимком каталога — следующие шаги; незавершённая полнота каталога не превращается в «ОН отсутствует». Тесты выполняются на настоящем коде локального репозитория.
