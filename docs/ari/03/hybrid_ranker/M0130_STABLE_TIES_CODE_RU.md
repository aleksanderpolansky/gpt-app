# M-0130 / ARI-03.06.06 — стабильная сортировка равных результатов на разных локалях

## 1. Требование утверждённого мастер-плана

**«Проверить стабильную сортировку ties на разных локалях».** Режим: `CODE`. Файл: `src/lib/ontology-research/hybridRankerV1.ts`; тесты в `scripts/tests/ari03-m0130-stable-ties-locales.test.cjs`.

## 2. Реализация

Новая чистая функция `rankHybridCandidatesStableTiesV1()` использует уже принятый M-0129 `rankHybridCandidatesGraphGatedV1()` и независимо проверяет порядок соседних объектов. Она **не пересортировывает** результаты, не изменяет релевантность и не создаёт новые ОН.

Утверждённый порядок при сравнении:

1. Уровень совпадения: полное каноническое название > подтверждённый активный алиас > обычный результат RRF.
2. При одинаковом уровне — значение RRF, по убыванию.
3. При равном RRF — меньший ранг лексического поиска, отсутствующий ранг после присутствующего.
4. Далее — меньший ранг векторного поиска, отсутствующий после присутствующего.
5. При полном равенстве — **канонический UUID в ASCII-порядке**, независимо от языка интерфейса.

Текст названия, локальные правила сортировки (collation), алфавит, акценты и регистр не применяются для разрешения ties: одно и то же множество кандидатов с теми же рангами должно давать одинаковый порядок для `en`, `pl`, `es`, `de`, `cs`, `uk`, `ru`.

Дополнительно результат содержит `tiesDetected`, `tieGroups`, `orderVerified`, `localeCollationUsed:false` и машинный идентификатор алгоритма. При нарушении ожидаемого порядка — `ok:false`, `TIE_ORDER_DRIFT`, без выдачи кандидатов.
