- Целевой ОН — действительный глобальный UUID `bf6b8ca1-97b4-56c3-a115-f76e2e7fec5a`, название `Night sleep`.
- Контрольные 18 ОН и метка русского exact запроса получены из ранее утверждённого owner Gold M-0121.
- Запускается **реальная функция** `rankHybridCandidatesStableTiesV1` из принятого `hybridRankerV1.ts`.
- Для каждого языка предлагаются два ранжированных источника по 18 кандидатов; целевой объект намеренно поставлен последним в обоих источниках. Это проверяет именно приоритет exact title, а не случайное первое место.

- Результат воспроизводится отдельным локальным отчётом с SHA-256 исходного Gold, версии алгоритма и тестового набора локалей.
