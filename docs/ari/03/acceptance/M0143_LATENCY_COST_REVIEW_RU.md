# M-0143 / ARI-03.08.05 — сравнение latency/cost с обозначением UNKNOWN

**Точное требование мастера:** «Сравнить latency/cost, включая индекс и запросы, не выдавать неизвестное за нуль».

**Режим:** ограниченный REVIEW. Не является приёмкой ARI-03 в целом, независимым holdout, подтверждением production SLA или вводом индекса в эксплуатацию.

## Первичные свидетельства

1. M-0138 — фактически измеренные локальные p50/p95 на 18 ОН и 36 запросах для `text-embedding-3-small` и `text-embedding-3-large`, холодный и прогретый *прикладной* каталог. Вход берётся из приватных доказательств, а значения сверяются с уже принятой квитанцией M-0138. Данные не включают запросы к PostgreSQL, HTTP, сетевую задержку, физическое чтение HNSW и полный каталог.
2. M-0124 — зафиксированные на 03.11.2026 тарифные предположения и 18 сценариев стоимости генерации embeddings. Оценки **provider-only**, не фактические счета или бюджет будущей инфраструктуры. Реальный OpenAI API при M-0143 не вызывается.
3. M-0131 — отчёт качества на 36 проверках (18 точных и 18 семантических), утверждённые владельцем метки. **Не независимый слепой holdout**.
4. M-0142 — stage/holdout freeze и SHA исходников/кода индексирования. **Не** отпечаток действующего физического индекса БД.

## Правила вывода

- Каждая величина маркируется `MEASURED`, `ESTIMATED_SCENARIO` либо `UNKNOWN`.
- При `UNKNOWN`: `value: null`, обязательна причина. Не превращать в `0`, не строить ложных сравнений и ratios.
- Для ARI-02 нет методологически сравнимого замера p95 в том же режиме и в той же среде: `UNKNOWN`.
- Для реального PostgreSQL/pgvector index build, query p95, RLS, HTTP и инфраструктурных затрат: `UNKNOWN`.
- В категории top1 на утверждённом корпусе показатели гибрида улучшились, однако доля нерелевантных кандидатов среди top5 в M-0131 стала **выше**. Должно быть явно отмечено как ограничение/проблема будущего production-gate.
- Ограниченный REVIEW может быть принят как корректное сравнение известных величин с явными пробелами. Запуск production по нему **не разрешается**.
- Платные действия автоматически запрещены, cash/provider billing не проверяется, SQL и deploy не выполняются.

## Результат

В приватной `docs/recovery/ARI_MASTER/03` создаются доказательства, исходные отчёты, новый структурированный отчёт сравнения, SHA, TAP/TS проверка и квитанция. Только после завершения проверки обновляется приватный ledger. Если что-либо не совпало, пакет останавливается без приёмки. Следующий шаг: M-0144.

## Примечание по HOTFIX v2
Диагностическая остановка v1 была вызвана обращением к отсутствующему экспорту `typecheck` M-0142. HOTFIX v2 использует публичный экспорт M-0141. Семантика latency/cost, источник измерений и запрет подмены UNKNOWN нулём не изменяются.
