# ARCTor · M-0121 / ARI-03.05.04 · Сравнение двух мультиязычных embedding-моделей

**Статус поставки:** PREPARATION ONLY. Шаг M-0121 НЕ считается принятым, пока фактически не получены и не оценены два набора выходов разных моделей на идентичном held-out наборе. Дорожная карта и приватный ledger остаются на M-0120 (118/615).

## Проверяемое задание

Две мультиязычные модели тестируются на **одном и том же заранее замороженном** наборе запросов, допустимых ON-кандидатов и вручную / по внутренней утверждённой политике размеченных соответствий. Оценка ранжирования производится одинаковым алгоритмом cosine similarity, Recall@1, Recall@5, MRR@5, nDCG@5 и в разрезе локализаций. Входные векторы передаются готовыми: сам оценщик **никогда** не вызывает OpenAI или иной провайдер, не делает SQL, не устанавливает pgvector и не меняет продукт.

## Кандидаты (не результаты)

1. OpenAI `text-embedding-3-small`, штатная размерность 1536; цена по публичной документации OpenAI на 2026-11-02: $0.02 за миллион входных токенов.
2. OpenAI `text-embedding-3-large`, штатная размерность 3072; аналогично $0.13 за миллион входных токенов.

Это **кандидаты для планирования**, а не запуск модели и не доказательство её пригодности к ARCTor. Возможно другое решение по провайдеру после cost/privacy review. Для измерения качества двух моделей необходимо получить настоящие выходы с подтверждаемыми источниками, версией модели и схемой ввода. Предварительная стоимость: `количество входных токенов / 1_000_000 × ставка`, плюс потенциальные повторные вызовы; конечная сумма зависит от реальной токенизации. Явное согласие владельца на денежный лимит обязательно ДО любых вызовов; никаких скрытых/автоматических затрат.

## Состояние Gold

В приватном журнале ранее отмечен Gold `M0049_GOLD_FULL_27.json` (27 сценариев); аннотированных случаев 7, суждений 69; `annotation_method=AI_ASSISTED_OWNER_INTERNAL_REVIEW_NOT_INDEPENDENT_GOLD`. Отсюда нельзя утверждать наличие независимого репрезентативного held-out Gold для семи языков. Сверить хеш файла, исключить случаи без релевантных UUID и без подтверждённой принадлежности к разрешённому каталогу; не подменять `knownRelevantIds=[]` догадкой. Если Gold недостаточен, статус **QUALITY_INCONCLUSIVE**. Для сравнения необходимы одни и те же query IDs, ON IDs, определения, источники и версии у обеих моделей. Система не должна допускать утечки приватных ОН между пользователями и строить embedding из приватных данных без отдельного разрешения.

## Отдельный gate M-0121

Этот пакет проверяет подготовленность локального окружения и алгоритма оценивания; НЕ генерирует реальных векторов. До получения пары реальных модельных результатов `M-0121: PENDING` и `lexical-only`. Для будущей реальной оценки дополнительно требуется: (1) cost approval; (2) privacy/scope audit; (3) замороженный согласованный Gold; (4) одинаковая версия источников для обоих кандидатов; (5) evaluation receipt с проверкой происхождения.

Факт прохождения контрактных тестов scorer ≠ сравнение двух моделей на Gold. Запрещено утверждать, что Recall, MRR или NDCG измерены по ARCTor, пока не поступили реальные векторы.

## Формат офлайн-оценщика

Команда `node scripts/tools/arctor-m0121-score.cjs path/to/benchmark.json` принимает JSON:

```
{
  "contract":"ARCTOR_M0121_PRECOMPUTED_TWO_MODEL_EVAL_V1",
  "goldSha256":"<64 uppercase hex>",
  "source":"OWNER_SUPPLIED_PRECOMPUTED_REAL_MODEL_OUTPUTS",
  "models":[{"id":"model-a","provenance":"..."},{"id":"model-b","provenance":"..."}],
  "queries":[{"id":"q1","locale":"ru","relevantOnIds":["on-1"]}],
  "candidates":[{"id":"on-1"},{"id":"on-2"}],
  "embeddings":{
    "model-a":{"queries":{"q1":[1,0]},"candidates":{"on-1":[1,0],"on-2":[0,1]}},
    "model-b":{"queries":{"q1":[0,1]},"candidates":{"on-1":[1,0],"on-2":[0,1]}}
  }
}
```

Векторы из примера исключительно **синтетические** и используются только для теста алгоритма. Если подан некорректный набор, оценщик прекращает работу. Не включать в общий ZIP реальные приватные тексты, идентификаторы пользователей, токены и сырые embeddings без необходимости.
