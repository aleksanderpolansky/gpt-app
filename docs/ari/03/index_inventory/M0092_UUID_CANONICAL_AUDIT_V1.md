# M-0092 — canonical_key и UUID активных объектов наблюдения

**Приёмка:** `ACCEPTED_READONLY_IDENTITY_AUDIT_ONLY`, не сертификат пригодности индекса.

* Всего ОН: 803; явно активных: 791; статусов вне оговоренной классификации: 0.
* У активных отсутствует canonical_key: 2; конфликтных групп нормализованных ключей в пределах namespace: 0 (строк в группах: 0).
* UUID column native type + primary key: YES. Это не удостоверяет корректность ссылок.
* Повторная проверка алиасов: 89 записей, 89 ссылок без целевого ОН (изменение к M-0091: 0).

* Содержимое канонических ключей, UUID и частные идентификаторы не публикуются; полный SQL-экспорт только в ARI_MASTER.
* Разрешено к индексированию: 0. Качество поиска INCONCLUSIVE. ARI-03 Indexed Search OFF.
