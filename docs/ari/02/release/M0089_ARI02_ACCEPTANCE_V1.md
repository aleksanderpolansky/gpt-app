## 3. Открытые дефекты и вопросы качества

1. **ARI02-RANK-EXACT-NIGHT-SLEEP-001 — OPEN_UNFIXED.** По фразе «ночной сон» experimental ставит родительский «Сон» выше точного «Ночной сон»; исходный baseline приоритет точного названия сохранял. Это установленное наблюдение на замороженном HTTP-трейсе, но не доказательство дефекта будущего ARI-03 поиска.
2. **ARI02-CONTEXT-SLEEP-STAIRS-001 — OPEN_UNFIXED.** Baseline выдавал «Подъём по лестнице» для «продолжительность сна» на шестой позиции; определение содержит общее слово «продолжительность».
3. **ARI02-CONTEXT-SLEEP-WALK-DURATION-001 — OPEN_UNFIXED.** Аналогично baseline выдавал «Длительность ходьбы» на восьмой позиции. Эти два дефекта не приписываются experimental.
4. **ARI02-HISTORICAL-NORESULTS-CATALOG-SON-001 — OPEN_HISTORICAL_REPRODUCTION_PENDING.** Историческое сообщение о пустой выдаче «сон» не снабжено исходным HTTP-ответом, точным commit и сопоставимым снимком; текущую неисправность оно не доказывает.
5. Словарные эвристики experimental ограничены: нет полной мультиязычной нормализации/морфологии; гипотезы связей не являются подтверждёнными отношениями.
6. Срезы каталога отмечены как partial (740 наблюдавшихся ОН и 7 шаблонов); глобальный полный состав, актуальный контентный fingerprint и exhaustive relevant set не подтверждены.

## 4. Непреодолимые данным отчётом ограничения

- `INCONCLUSIVE` — корректный результат при недостаточном полном scope и разметке, а не ошибка выполнения M-0089.
- `Precision@10`, `nDCG@10` могут иметь только явно помеченную ограниченную область применимости; не использовать их как подтверждение качества всех пользовательских запросов.
- Реальный `Recall@20=N/A` из-за отсутствия независимо проверенного полного набора релевантных ОН.
- Пары baseline/experimental в одном HTTP-ответе сопоставимы на общем in-memory наборе, однако стабильность каталога **между** всеми ответами не доказана.
- Нет корректного before/after релиза нового алгоритма, нет доказанного улучшения, нет независимого E2E ARI-03.
- Человеческие оценки зависят от пользовательской цели, опыта, контекста; персональные связи живут в графе пользователя, а не автоматически в глобальной структурной иерархии ОН.

## 5. Границы перехода к ARI-03

**Разрешено по утверждённой дорожной карте без переключения алгоритма:** M-0090 — read-only ревизия источников локализованных title/description/canonical_key и проверки scope/version; M-0091 и дальнейшие read-only исследования алиасов и контрактов. Выявленное неизвестное поле отмечается `UNKNOWN/EXCLUDED` до проверки, а не заполняется предположением.

**Не разрешено данным документом:** изменение SQL/RLS/GRANT, создание индекса, миграция, запись в каталог, изменение продакшен-маршрутизации, включение `ARCTOR_ON_INDEXED_LOOKUP_V1`, commit/push/deploy, присвоение `GOLD_CONFIRMED` одной личной оценке. Эти действия требуют своих шагов и конкретного разрешения, когда оно необходимо.

Перед любым будущим включением поиска: зафиксировать версию и поля каталога; подтвердить права и изоляцию пользователей; обеспечить тестовые данные с контролируемым scope, безопасность, метрики, поведение при пустом результате, канареечное тестирование и откат, а также контроль стоимости и доступа. Открыты риски **R01, R02, R09, R14**.
