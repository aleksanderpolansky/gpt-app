# ARI-02 — классы ошибок поиска v1 (M-0078)

Это **словарь квалификации дефектов**, не классификатор, который автоматически объявляет баги доказанными. Для одной ошибки допустимо несколько проверенных классов. Само отсутствие класса означает `UNDETERMINED`, не новый седьмой класс.

| Код | Когда применять | Что не является доказательством |
|---|---|---|
| `wrong_facet` | Неверный аспект/ракурс ОН относительно запроса, проверенный по содержанию и контексту | Просто похожее слово |
| `wrong_sense` | Нерелевантный смысл фразы или понятия | Общее название выше точного без отдельной оценки смысла |
| `translation` | Проверенная проблема переводов или алиасов в определённой локали | Пустой ответ без проверки границ каталога |
| `path_only` | Сработало только имя предка/путь, а сам найденный ОН нерелевантен | Само совпадение по пути |
| `duplicate` | Дубли одного UUID или доказанная идентичность разных UUID | Похожие названия |
| `truncation` | Документированное ограничение выборки, скрывающее полноту | Обычная корректная пагинация |

## Правила применения

1. Для подтверждения класса нужны `defect_id`, query, locale, версия, режим, UUID и ранги (или явно засвидетельствованное отсутствие), источник с SHA256, причина и ожидаемое поведение. Если нет нужных доказательств, оставлять `CANDIDATE_REVIEW_REQUIRED` или `UNDETERMINED`, не `CONFIRMED`.
2. M-0075: инверсия «Ночной сон» / «Сон» подтверждена как порядок результатов; **не доказывает** `wrong_sense`.
3. M-0076: ходьба и лестница в выдаче «продолжительность сна» — подтверждённые архивные попадания по тексту определения; `wrong_sense` является **кандидатом** до рецензии куратора.
4. M-0077: историческое сообщение о пустой выдаче — **нет первичного старого HTTP-ответа**; `truncation`, `translation` и другие причины неизвестны.
5. Новому ARI-03 indexed lookup эти случаи не приписывать. `Recall@20` на неполном реальном каталоге остаётся `N/A`.
6. M-0079 отдельно свяжет defect_id с gold case_id, source SHA и режимом поиска. Не объявлять это сделанным заранее.

Код не меняет работу существующего поиска. `src/lib/ontology-research/ari02ErrorClassesV1.ts` — новый автономный справочный модуль, без включения в активный API. Приватный реестр находится в `docs/recovery/ARI_MASTER` и не должен попасть в Git.
