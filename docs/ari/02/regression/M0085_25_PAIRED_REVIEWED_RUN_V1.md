- Прогнано **25** сценариев на **7** языках, **166** оценок первого рецензента. Оценки не превращены в универсальные онтологические связи.
- Две выдачи из каждого одного HTTP-ответа; 25 ответов получены в разные моменты, без глобального отпечатка каталога.
- Полных Top-10: baseline **10**, experimental **5**, одновременно **5**. Четыре пустые пары подтверждены как *пустая выдача*, не отсутствие объекта в базе.

- **Общий regression gate: INCONCLUSIVE.** Не переименовывать в PASS. Отсутствие полного каталога и сравнения версий остаётся ограничением ARI-02.
